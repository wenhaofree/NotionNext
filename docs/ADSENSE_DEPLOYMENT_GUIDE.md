## 🚀 部署步骤

### 步骤 1: 环境配置

1. **复制环境变量文件**
   ```bash
   cp .env.example .env.local
   ```

2. **配置基本信息**
   ```bash
   # 必填配置
   NOTION_PAGE_ID=your_notion_page_id
   NEXT_PUBLIC_THEME=heo
   NEXT_PUBLIC_LANG=zh-CN
   
   # SEO 配置
   SEO_GOOGLE_SITE_VERIFICATION=your_verification_code
   SEO_BAIDU_SITE_VERIFICATION=your_verification_code
   ```

3. **配置 AdSense (申请通过后)**
   ```bash
   # AdSense 配置
   NEXT_PUBLIC_ADSENSE_ENABLED=true
   NEXT_PUBLIC_ADSENSE_PUBLISHER_ID=ca-pub-xxxxxxxxxxxxxxxx
   NEXT_PUBLIC_ADSENSE_SLOT_TOP=1234567890
   NEXT_PUBLIC_ADSENSE_SLOT_IN_ARTICLE=1234567891
   NEXT_PUBLIC_ADSENSE_SLOT_BOTTOM=1234567892
   NEXT_PUBLIC_ADSENSE_SLOT_SIDEBAR=1234567893
   ```

### 步骤 2: 内容准备

1. **创建高质量内容**
   - 确保每篇文章都是原创内容
   - 文章长度至少 800 字
   - 包含有价值的信息和见解
   - 添加相关图片和媒体

2. **优化现有内容**
   - 检查并修复语法错误
   - 添加内部链接
   - 优化标题和描述
   - 添加相关标签和分类

3. **内容结构优化**
   ```markdown
   # 文章标题 (H1)
   
   ## 引言 (H2)
   简要介绍文章主题和价值
   
   ## 主要内容 (H2)
   ### 子主题 1 (H3)
   详细内容...
   
   ### 子主题 2 (H3)
   详细内容...
   
   ## 总结 (H2)
   要点回顾和行动建议
   
   ## 相关资源 (H2)
   参考链接和延伸阅读
   ```

### 步骤 3: 网站优化

1. **性能优化**

2. **SEO 优化**

   - 优化移动端加载速度

## 📊 AdSense 申请流程

### 申请前准备

1. **网站运营时间**
   - 建议运营至少 3-6 个月
   - 有稳定的内容更新频率
   - 有一定的访问量

2. **内容质量要求**
   - 至少 30 篇高质量原创文章
   - 每篇文章 1000+ 字
   - 内容有实用价值
   - 无版权问题

3. **网站完整性**
   - 所有必要页面都已创建
   - 网站导航清晰
   - 无死链接
   - 加载速度快

### 申请步骤

1. **访问 AdSense 官网**
   - 前往 [Google AdSense](https://www.google.com/adsense/)
   - 使用 Google 账户登录

2. **添加网站**
   - 输入您的网站 URL
   - 选择国家/地区
   - 选择付款货币

3. **网站审核**
   - Google 会审核您的网站
   - 审核时间通常为 1-14 天
   - 保持网站正常运营

4. **处理审核结果**
   - 如果通过：开始配置广告
   - 如果拒绝：根据反馈优化网站

## 🔧 常见问题解决

### "低价值内容" 问题

**问题原因：**
- 内容质量不够高
- 文章太短或缺乏深度
- 重复或抄袭内容
- 网站结构不完整

**解决方案：**
1. 提高内容质量
   - 增加文章长度和深度
   - 确保内容原创性
   - 添加实用价值

2. 完善网站结构
   - 添加必要的法律页面
   - 优化导航和用户体验
   - 提高网站专业性

3. 增加内容数量
   - 发布更多高质量文章
   - 保持定期更新
   - 建立内容主题集群

### "网站导航" 问题

**解决方案：**
- 添加清晰的主导航菜单
- 实现面包屑导航
- 创建网站地图
- 优化内部链接结构

### "用户体验" 问题

**解决方案：**
- 优化页面加载速度
- 改善移动端体验
- 减少侵入性元素
- 提高内容可读性
